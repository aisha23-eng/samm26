Python → PHP

A practical guide for Python developers learning PHP

Python 3 PHP 8+
You know Python. Now you need PHP. Maybe it's Laravel. Maybe it's a WordPress gig. Maybe you just want another tool in the belt. The syntax looks different — $ everywhere, semicolons, arrows instead of dots — but the concepts map directly. This guide skips the "what is a variable" intro and goes straight to the translation table.

Basic Syntax

variables, comments, types
Python uses indentation to define blocks; PHP uses braces. PHP variables always start with $ and don't need a keyword to declare. Both are dynamically typed.
Python
# This is a comment
name = "Alice"
age = 30
is_admin = True
price = 49.99
items = None

# Type hint (optional)
def greet(n: str) -> str:
    return f"Hello, {n}"
PHP
<?php
// This is a comment
$name = "Alice";
$age = 30;
$isAdmin = true;
$price = 49.99;
$items = null;

// Type hint (optional)
function greet(string $n): string {
    return "Hello, $n";
}
Note: PHP files need an <?php opening tag. The closing ?> is optional and usually omitted in pure PHP files to prevent accidental whitespace output.

Strings

concatenation, interpolation, methods
Python uses . for concatenation and f-strings for interpolation. PHP uses . too, and interpolates variables directly inside double-quoted strings.
Python
# Concatenation
msg = "Hello, " + name

# f-string interpolation
msg = f"Hello, {name}"

# Methods
upper = "hello".upper()
length = len("hello")
parts = "a,b,c".split(",")
joined = ", ".join(["a", "b"])
PHP
// Concatenation
$msg = "Hello, " . $name;

// Double-quote interpolation
$msg = "Hello, $name";

// Methods
$upper = strtoupper("hello");
$length = strlen("hello");
$parts = explode(",", "a,b,c");
$joined = implode(", ", ["a", "b"]);
Watch out: PHP string functions are not methods on the string — they're standalone functions that take the string as the first argument. Method-style calls exist on Stringable objects in Laravel, but in raw PHP you use functions.

Arrays & Dicts

indexed arrays, associative arrays, operations
PHP arrays are ordered maps that serve double duty as both indexed lists and key-value stores — a single type does what Python splits between list and dict.
Python
# List (indexed)
fruits = ["apple", "banana"]
fruits.append("cherry")
fruits[0]          # "apple"
len(fruits)        # 3

# Dict (associative)
user = {
    "name": "Alice",
    "age": 30
}
user["email"] = "a@b.com"
user.get("name")   # "Alice"
PHP
// Indexed array
$fruits = ["apple", "banana"];
$fruits[] = "cherry";
$fruits[0];          // "apple"
count($fruits);      // 3

// Associative array
$user = [
    "name" => "Alice",
    "age" => 30
];
$user["email"] = "a@b.com";
$user["name"];       // "Alice"
Python
# Looping
for f in fruits:
    print(f)

for k, v in user.items():
    print(k, v)

# Membership
if "apple" in fruits: ...
if "name" in user: ...

# Dict comprehension
squares = {x: x**2 for x in range(5)}
PHP
// Looping
foreach ($fruits as $f) {
    echo $f;
}

foreach ($user as $k => $v) {
    echo "$k: $v";
}

// Membership
if (in_array("apple", $fruits)) ...
if (array_key_exists("name", $user)) ...

// No direct comprehension equivalent
// Use array_map / array_filter
Key difference: Python dicts are unordered (though insertion-ordered since 3.7). PHP arrays are ordered — the => arrow preserves insertion order natively. Also, in_array() is O(n) — for lookup-heavy code use $array[$key] with associative arrays.

Control Flow

if, for, while, match
Python
# if / elif / else
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"

# for loop
for i in range(5):
    print(i)

# while loop
while x > 0:
    x -= 1

# match (3.10+)
match status:
    case 200: ...
    case 404: ...
PHP
// if / elseif / else
if ($score >= 90) {
    $grade = "A";
} elseif ($score >= 80) {
    $grade = "B";
} else {
    $grade = "C";
}

// for loop
for ($i = 0; $i < 5; $i++) {
    echo $i;
}

// while loop
while ($x > 0) {
    $x--;
}

// match (8.0+)
$grade = match ($status) {
    200 => ...
    404 => ...
};

Functions

named, anonymous, type hints
Python
def add(a, b):
    return a + b

# Default args
def greet(name, prefix="Hello"):
    return f"{prefix}, {name}"

# Type hints
def multiply(x: int, y: int) -> int:
    return x * y

# Lambda
square = lambda x: x ** 2

# *args / **kwargs
def log(*items, **opts):
    print(items, opts)
PHP
function add($a, $b) {
    return $a + $b;
}

// Default args
function greet($name, $prefix = "Hello") {
    return "$prefix, $name";
}

// Type hints
function multiply(int $x, int $y): int {
    return $x * $y;
}

// Arrow fn / Closure
$square = fn($x) => $x ** 2;

// Variadic args
function log(...$items) {
    var_dump($items);
}

// Named args (PHP 8+ call-site feature,
// no **kwargs equivalent)
log(items: ["a"], prefix: "x");

Classes & Objects

constructor, inheritance, visibility
Python
class User:
    def __init__(self, name, email):
        self.name = name
        self.email = email

    def say_hello(self):
        return f"Hi, I'm {self.name}"

class Admin(User):
    def __init__(self, name, email, role):
        super().__init__(name, email)
        self.role = role

user = User("Alice", "a@b.com")
print(user.say_hello())
PHP
class User
{
    public function __construct(
        public string $name,
        public string $email
    ) {}

    public function sayHello(): string
    {
        return "Hi, I'm {$this->name}";
    }
}

class Admin extends User
{
    public function __construct(
        string $name,
        string $email,
        public string $role
    ) {
        parent::__construct($name, $email);
    }
}

$user = new User("Alice", "a@b.com");
echo $user->sayHello();
Constructor promotion: PHP 8.0+ lets you declare and assign properties directly in the constructor signature — similar to Python dataclasses. Visibility (public, protected, private) is explicit and enforced.

File I/O

read, write, JSON
Python
with open("file.txt") as f:
    content = f.read()

with open("file.txt", "w") as f:
    f.write("Hello")

import json
data = json.loads(content)
output = json.dumps(data, indent=2)
PHP
$content = file_get_contents("file.txt");

file_put_contents("file.txt", "Hello");

$data = json_decode($content, true);
$output = json_encode($data, JSON_PRETTY_PRINT);

Error Handling

try / catch / finally
Python
try:
    result = risky_operation()
except ValueError as e:
    print(f"Oops: {e}")
except Exception as e:
    print(f"Unknown: {e}")
finally:
    cleanup()
PHP
try {
    $result = riskyOperation();
} catch (\ValueError $e) {
    echo "Oops: {$e->getMessage()}";
} catch (\Throwable $e) {
    echo "Unknown: {$e->getMessage()}";
} finally {
    cleanup();
}

Web Context

superglobals, routing, Laravel notes
Python web frameworks (Flask, Django) use explicit request objects. PHP has superglobals — predefined arrays available everywhere. If you're learning PHP for Laravel (your project), you'll use Laravel's request wrapper instead, but the underlying superglobals are good to know.
Flask / Django
# Flask
from flask import request
name = request.args.get("name")
data = request.form.get("email")

# Session
session["user_id"] = 42

# Redirect
return redirect("/dashboard")
Laravel / Raw
// Laravel
$name = $request->query("name");
$data = $request->input("email");

// Raw PHP
$name = $_GET["name"] ?? null;
$data = $_POST["email"] ?? null;
$_SESSION["user_id"] = 42;
header("Location: /dashboard");
Laravel-specific: Since your project uses Laravel + Inertia, you'll work with Eloquent models (PHP's ORM), Blade or Inertia templates, and Artisan CLI. The $ sigil, -> for methods/properties, and use for imports are the daily bread. Most of your logic lives in controllers and Eloquent models — think of them like Flask blueprints + SQLAlchemy models combined.
